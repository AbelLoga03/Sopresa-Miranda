# Guía para personalizar la sorpresa

Cuando quieras convertir la demo en la versión definitiva, prepara esta información:

1. Fecha del cumpleaños.
2. Una fecha importante para calcular días.
3. Entre 8 y 15 fotos.
4. Qué significa cada foto o cuándo se hizo.
5. 3–6 fechas para la línea temporal.
6. 5 razones o pequeños detalles que quieras destacar.
7. 3 preguntas del minijuego con sus respuestas.
8. 4 mensajes de “Ábrelo cuando…”.
9. 4 planes futuros.
10. Una carta final.
11. Qué será la sorpresa o regalo final.
12. Si quieres, una canción o música libre de derechos.

## Nombres recomendados para las fotos

- images/01-comienzo.jpg
- images/02-primera-cita.jpg
- images/03-recuerdo.jpg
- images/04-favorita.jpg
- images/05-viaje.jpg

No hace falta usar esos nombres exactos: sirven para mantener el repositorio ordenado.

## Privacidad

Este repositorio es público. No subas fotos o información que quieras mantener privada. Cualquier archivo publicado en GitHub Pages puede acabar siendo accesible mediante su URL.
