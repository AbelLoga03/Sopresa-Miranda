# Sorpresa para Miranda

Primera versión de una web interactiva de cumpleaños.

## Estructura

- `index.html`: contenido principal.
- `css/style.css`: diseño responsive.
- `js/app.js`: navegación e interacciones.

## Personalización pendiente

La versión actual usa textos y espacios de ejemplo. Antes de publicar la versión definitiva se pueden añadir:

- Fotos reales.
- Fechas y recuerdos.
- Preguntas del minijuego.
- Mensajes de “Ábrelo cuando…”.
- Carta final.
- Regalo o sorpresa final.
- Música elegida por el autor.

## Publicación

El proyecto está preparado como web estática y es compatible con GitHub Pages.
